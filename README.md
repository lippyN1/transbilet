# ТрансБилет — покупка билетов на транспорт

Учебный проект по интернет-технологиям.
Вариант 17, группа Б — «Заказ и бронирование».
Основной сценарий: выбор даты и места, занятые места недоступны.

## Тема

Сайт для покупки билетов на междугородний транспорт
(автобус, поезд, самолёт). Пользователь находит рейс, выбирает
свободное место и оформляет билет. Занятые места видны на схеме
и недоступны для выбора.

## Как запустить

Проект — статический. Все данные хранятся в браузере (localStorage).
