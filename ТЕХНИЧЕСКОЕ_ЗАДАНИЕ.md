# Техническое задание WayGo

## Назначение
Учебный веб-сервис поиска и бронирования билетов на самолёт, поезд и автобус.

## Страницы
1. Главная — назначение сервиса, форма поиска, популярные направления.
2. Каталог — список маршрутов, фильтры по направлению и типу транспорта, сортировка.
3. Маршрут — информация о выбранном рейсе, цена и переход к выбору места.
4. Бронирование — схема мест, создание бронирования и список билетов пользователя.
5. Контакты — информация о проекте и форма обратной связи.
6. Вход и регистрация — создание учётной записи и авторизация.

## Данные
- Пользователь: имя, email, хеш пароля, дата регистрации.
- Маршрут: города, коды, перевозчик, тип транспорта, время, дата, длительность, стоимость.
- Бронирование: пользователь, маршрут, место, имя пассажира, время создания.
- Сообщение: имя, email, текст, дата отправки.

## Поведение
Гость может просматривать маршруты и каталог. Для бронирования требуется вход. Место после бронирования становится недоступным всем пользователям. Форма обратной связи сохраняет сообщение в SQLite. Каталог и действия интерфейса обращаются к API через `fetch`.

## Ограничения учебной версии
Цены и рейсы демонстрационные; платежи и выдача реальных транспортных документов не выполняются. Внешний API используется для демонстрации получения курса валют.
